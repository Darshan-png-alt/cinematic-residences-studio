# Dubai Canvas

Build a premium, cinematic real-estate project website from scratch.

This is a conceptual residential development website. The visual reference is a printed luxury real-estate brochure that follows a specific storytelling order and section placement. The website must preserve the same overall content flow and placement logic of the reference, but it must NOT look like the brochure was simply converted into web pages.

IMPORTANT DESIGN DIRECTION:

Premium modern architecture

High-end Dubai-inspired real-estate aesthetic

Cinematic and editorial

Minimal but visually rich

Sophisticated typography

Large architectural imagery

Generous whitespace

Elegant transitions and subtle motion

Nature + architecture visual language

Strong sense of depth and layering

The website should feel expensive, immersive and professionally designed

The project identity is temporary and must be easy to replace later. Use a placeholder project name and placeholder logo rather than committing to a final brand identity.

HERO EXPERIENCE:
Create a visually impressive full-screen opening section.

The opening should feel like entering an architectural presentation rather than a normal real-estate website.

Use large elegant typography that appears through a soft fade/reveal animation. Text should feel cinematic and restrained.

Behind and around the typography, introduce a large architectural residential-building visual with layered depth.

The building should feel like a designed visual object rather than a normal image sitting inside a rectangular card.

As the user begins scrolling:

Typography should transition smoothly

The architectural visual should subtly scale/move

Layers should create depth

The next content should progressively reveal itself

Motion must remain elegant and smooth rather than flashy

Use temporary high-quality architectural imagery that can easily be replaced later.

BROCHURE-INSPIRED VISUAL LANGUAGE:
Use subtle references to the supplied brochure style:

Botanical line-art

Trees and floral illustrations

Thin architectural lines

Circular/geometric forms

Editorial layouts

Layered photography

Refined decorative elements

Do NOT directly copy illustrations or artwork from the brochure. Recreate the feeling with original/different visual elements.

SECTION STRUCTURE:
Keep the overall storytelling sequence and major placement logic of the brochure:

Opening / project introduction

Project identity and concept

Architecture / building

Lifestyle and amenities

Nature / landscape

Community / master plan

Residences / floor plans

Location

Final enquiry / contact section

The exact content, project name, images, quotes, logo and project information will be customised later.

TECHNICAL REQUIREMENTS:

Build using a modern React-based frontend.

Make the architecture modular and easy to edit.

Use reusable components.

Fully responsive for desktop, tablet and mobile.

Prioritize smooth performance.

Avoid unnecessary libraries.

Use clean, maintainable code.

Do not create a generic template-looking real-estate website.

Do not use excessive gradients, glowing effects, neon effects or random 3D effects.

Animations should support the architecture and storytelling.

Ensure text remains readable and accessible.

Keep all placeholder content easy to replace.

For this first version, focus heavily on establishing the visual identity, navigation and the cinematic hero experience. Build enough of the following section to make the transition from the hero feel intentional, but do not spend effort filling every later section with detailed content yet.

The final experience should feel like a premium architectural presentation, not a brochure pasted onto a webpage.
